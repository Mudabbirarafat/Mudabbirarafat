- 🔭 Currently shipping backend and AI features on a live job board
- 🧰 Strongest at API design, Postgres data modelling, and turning a vague spec into something deployed
- 🌱 Learning distributed systems, caching strategy, and measurement that survives review
- 💬 Ask me about Flask/FastAPI auth, Next.js app router, or getting a side project actually live
